# Hospital Management System

## Overview

The Hospital Management System is a simple Java-based application designed to manage basic hospital operations.

## Features

1. Patient Registration
2. Doctor Management and Scheduling
3. Appointment Booking
4. Patient Medical History
5. Doctor Availability

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner

## Modules

### 1. Patient Registration
Allows users to register patients by entering their name, age, gender, phone number, and medical history.

### 2. Doctor Management
Allows users to add doctors with their specialization, phone number, consultation fee, and available schedule.

### 3. Appointment Booking
Allows users to book appointments by selecting a patient and doctor and entering the appointment date, time, and reason for visit.

### 4. Patient Medical History
Displays registered patient details and their medical history.

### 5. Doctor Availability
Displays doctor information, specialization, consultation fee, and available schedule.
